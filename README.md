# 🎵 Online Music Streaming App (Android)

An **online music streaming Android application** built using **Jetpack Compose** and modern Android development tools.

The app allows users to stream music online with a **smooth, responsive UI**, following **clean architecture** and **best practices**.

---

## ✨ Features

- 🎧 Online music streaming
- ▶️ Background playback using **Android Media3**
- 🧭 Seamless navigation with **Jetpack Navigation (Compose)**
- ⚡ Fully built with **Jetpack Compose**
- 🧩 Clean architecture using **MVVM**
- 🔌 Dependency Injection with **Koin**
- 🌐 Network communication using **Ktor**
- 🚀 Scalable and maintainable codebase

---

## 🛠 Tech Stack

- **Language:** Kotlin  
- **UI:** Jetpack Compose  
- **Media Playback:** Android Media3  
- **Architecture:** MVVM  
- **Navigation:** Jetpack Navigation (Compose)  
- **Dependency Injection:** Koin  
- **Networking:** Ktor Client  
- **State Management:** ViewModel + StateFlow  

---

## 📐 Architecture Overview

The application follows the **MVVM (Model–View–ViewModel)** architecture:

- **UI Layer:** Jetpack Compose screens
- **ViewModel Layer:** Handles UI state and business logic
- **Data Layer:** Ktor API client and repositories
- **Player Layer:** Media3 for music streaming and playback

This structure ensures:
- Separation of concerns
- Better testability
- Easy scalability and maintenance
